# True Shot

A fictional-content basketball game for phone and desktop, with three modes on one shared simulation:

- **GM mode:** run a franchise. Draft, trade, sign, develop, win.
- **Career mode:** create a player and develop them into a legend.
- **Dynasty mode:** collect cards from packs and auto-battle with your team.

This repository is built mostly by Claude Code under a plan-first workflow: every feature starts as a written plan that the owner approves by merging, and only then gets coded.

## Start here

1. Read `RUNBOOK.md` (setup and daily use).
2. Read `GAME_DESIGN.md` (what we're building) and `ROADMAP.md` (in what order).
3. `npm install && npm run verify`

AI sessions must follow `CLAUDE.md`.
